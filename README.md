# Invoza

> Beautiful invoices. Less admin.

Invoza is a modern invoice creation studio built for freelancers, independent professionals, creators, and small businesses who want to create professional invoices without unnecessary complexity.

Create an invoice in under a minute, customize its visual style, preview it instantly, and export a clean A4 PDF — without creating an account or dealing with unnecessary clutter.

---

## Features

### Fast Invoice Creation

Create professional invoices through a focused and easy-to-use editor.

- Add business information
- Add client information
- Add invoice number and dates
- Add multiple line items
- Set quantities and prices
- Apply taxes and discounts
- Add payment terms
- Add custom notes
- Set payment status

### Six Distinct Invoice Templates

Invoza comes with six visually different invoice designs. Each template has its own layout, hierarchy, typography, spacing, and visual personality.

#### 01 — Minimal

A clean and sophisticated design focused on typography, whitespace, and simplicity.

**Best for:** Freelancers, consultants, and professional services.

#### 02 — Modern

A contemporary layout using structured sections, rounded elements, and a polished visual hierarchy.

**Best for:** Startups, agencies, designers, and modern businesses.

#### 03 — Professional

A traditional business-oriented invoice with strong structure and clear financial information.

**Best for:** Corporate services, consultants, and established businesses.

#### 04 — Elegant

A refined editorial-style design with sophisticated typography, centered elements, and subtle visual details.

**Best for:** Creative professionals, premium services, and personal brands.

#### 05 — Bold

A high-contrast design with strong typography and prominent emphasis on important invoice information and totals.

**Best for:** Agencies, studios, creators, and brands with a stronger visual identity.

#### 06 — Creative

An expressive and asymmetric layout designed to give invoices more personality while remaining professional.

**Best for:** Designers, photographers, creators, and creative businesses.

> The templates are not simply color variations. Each one changes the actual composition and visual hierarchy of the invoice.
